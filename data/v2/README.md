# V2 Software Engineering Semantic Search Dataset
100 documents across 10 balanced IT domains; 1,000 training, 200 validation and 200 test query-to-document relevance pairs.

Integrity checks performed: unique document IDs, valid references, exact counts, no duplicate query within a split, and no exact query leakage across splits.

Important: this is a synthetic educational dataset. Many queries are template-assisted. V3 should add independently authored natural queries, typos/noise, multi-intent queries and human relevance judgments. Test scores here should not be treated as production-quality evidence.
